About ICD-10 codes

The International Classification of Diseases (ICD) is the World Health Organization's system for recording diagnoses. Clinicians, insurers and researchers use the codes to describe the same condition in the same way.

A code starts with a letter that marks the chapter (E for endocrine conditions, I for circulatory, J for respiratory) followed by numbers that add detail. E11.9, for example, is type 2 diabetes without complications.

The United States uses ICD-10-CM for diagnoses; Canada uses ICD-10-CA; many countries are moving to ICD-11. If a code on a bill or form looks wrong, ask your provider's billing office to review it.
